## Notes for whoever continues

- A new template needs one line in `MAIN_ROUTES` (`tests/e2e/helpers/uiBoost.ts`); both specs pick it up. The portal and account routes need `.playwright/audit-accounts.json` (`node scripts/qa/audit/accounts.mjs`), otherwise those tests are skipped.
- A running block is lifted by a transform: measure a reveal by the element's layout position (offsetTop chain), not by `getBoundingClientRect()`.
- An open Radix menu sets `pointer-events: none` on the body, so `elementsFromPoint` sees nothing under it. The corner audit finds neighbours by geometry for that reason.
- Radix puts `role="tooltip"` on a hidden copy beside the visible tooltip; a tooltip opens on focus only when the focus is keyboard-like — in a test, hover first.
- `next build` while `next start` serves the same `.next` breaks the running server: stop the server (by the PID you recorded), build, start again.
- Lighthouse has to run alone: screenshots or e2e in parallel cost 5–10 points.
