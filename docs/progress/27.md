## Notes

- Heredocs break on apostrophes: edit scripts live in `.playwright/tmp/*.py` (helper `edit.py` handles CRLF files).
- A full-page Playwright capture resizes the viewport: an element that is `hidden lg:block` replays its eager entrance into the picture (not a bug of the page).
- Never `cd` in a compound command without returning — the shell keeps the directory.
- Pipe `git add` / `git commit` output through `tail` (CRLF warnings flood otherwise).
- A module that does not compile makes the Turbopack dev server answer 500 on every route: with several workers on one dev server, run `npx tsc --noEmit` right after every scripted edit.
- `cn` joins class lists, it does not merge: a caller's utility cannot override a component's own (`Input h-9`, `EmptyState py-0`). Use a variant (`max-sm:`), a prop, or change the component.
- Results and numbers of the final run: the entry of 2026-10-12 in `docs/PROGRESS.md`.
