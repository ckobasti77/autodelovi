## Notes
- Heredocs break on apostrophes: edit scripts live in `.playwright/tmp/*.py` (helper `edit.py` handles CRLF files).
- A full-page Playwright capture resizes the viewport: an element that is `hidden lg:block` replays its eager entrance into the picture (not a bug of the page).
- Never `cd` in a compound command without returning — the shell keeps the directory.
- Pipe `git add` / `git commit` output through `tail` (CRLF warnings flood otherwise).
