# Step 16 — Excel import and exports

Continue in the admin you just built. The owner keeps his catalog in spreadsheets exported from his accounting software; importing must be fast, forgiving and safe. Manual one-by-one entry (step 15) remains the other path — both share the same validation.

## Build — /admin/uvoz
1. **Library** — SheetJS from the official CDN tarball (check the latest at https://cdn.sheetjs.com/), never the outdated npm `xlsx`; parse in a **Web Worker**. CSV: detect UTF-8 vs. Windows-1250 (common in Serbian exports) and the delimiter (`;` vs `,`); keep č ć ž š đ intact.
2. **Template** download (.xlsx): sheet „Proizvodi" with Serbian headers and header comments, „Uputstvo" (how to fill it), „Kategorije" and „Proizvođači" (valid values).
3. **Wizard**:
   - upload (xlsx / xls / csv, up to ~50 000 rows) → sheet and header-row detection
   - **column auto-mapping** by synonyms (šifra / sifra / SKU / artikal / kod; naziv; OEM / kataloški broj / kat. br. / originalni broj; zamenski / cross; proizvođač / brend; MP cena / VP cena / cena; količina / stanje / lager; kategorija; primena / vozilo / odgovara za; opis; slika URL; težina; nabavna cena) with manual override and **saved mapping presets**
   - **validation preview** (per-row errors and warnings, duplicates within the file, unknown categories with suggestions, price/quantity parsing including „1.234,56")
   - **dry-run diff** (create / update / unchanged / skip counts with sample rows)
   - mode: full upsert by SKU (fallback OEM + manufacturer) · only stock and prices · optional deactivate-missing behind a typed confirmation
   - **commit** in batches sized for Convex limits, live progress, idempotent per batch
   - **result** with counts and a downloadable error report (.xlsx)
4. **Records** — per-row change log with previous values, stock movements, audit log; **rollback** of an import restores previous values (and removes created products that were not touched since).
5. **Image URLs** column → a background action fetches and stores the images (rate-limited, size/type checked, failures reported).
6. **Import history** page: who, when, file, mode, counts, errors, rollback button.
7. **Exports**: products (.xlsx, round-trips with the template), orders (.csv), customers & mechanics (.csv).
8. **Fixtures** generated by a script: a 500-row xlsx with deliberate errors, a Windows-1250 CSV with diacritics and `;`, a stock-only file.

## Verify
Unit tests (mapping, parsing, number formats, encodings), convex-test (batch upsert, idempotency, rollback, authorization), Playwright (template download; upload the 500-row fixture → mapping → preview shows the seeded errors → commit → counts correct → rollback). tsc, lint, build and tests pass · commit · Step report.
